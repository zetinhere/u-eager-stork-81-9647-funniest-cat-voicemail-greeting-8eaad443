`main.py` scores a pool of 30 original one-line cat voicemail greetings against the judge brief published with the bounty and writes the winner to `/output/entry.txt`:

> Meow. I'm a cat. I don't do voicemail. I do 4 a.m. screaming. Leave a message anyway.

85 characters, one line. The cat refuses the medium, escalates to its signature crime (demanding food at four in the morning, loudly), then grudgingly complies with the voicemail close. The joke is cat-specific, the voice is all attitude, and the punch lands in the last words. The pick beats all 29 other candidates head-to-head on the brief's weighted criteria (voicemail + laugh x3, cat-specific x3, voice x2, spoken-aloud speed x2, freshness x1).

## Run it

```sh
python3 main.py   # writes /output/entry.txt, deterministic, no network
```
